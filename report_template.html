Read the denominator

How to interpret this dashboard

  • Check pass rate: passed rule checks ÷ all evaluated rule checks. Two rules apply to institution_id, so it contributes twice as many checks as a one-rule column.
  • Weighted quality score: each record starts at 100, then loses 100 × failed rule weights ÷ total rule weights. The dashboard averages the rounded record scores. Weights are illustrative policy choices, not measured risk probabilities.
  • Duplicate identifiers: every row sharing an identifier is flagged. Source row numbers distinguish records even when their institution IDs match.
  • Observed values: these are normalized values used during evaluation; whitespace-only and null values become blank. This report does not preserve original pre-normalization bytes.
  • Rule scope: email syntax is not email deliverability; a permitted state code does not establish address existence; recency is evaluated against the displayed as-of date.
  • Platform scope: the SQL folder contains SQLite-compatible reference queries. Those queries are not the execution engine for this dashboard. No Snowflake DMF, dbt job, or Tableau workbook was deployed.
  • Refresh: running pipeline.py regenerates the data outputs and standalone report. This published sample is a batch snapshot, not a continuously refreshed production monitor.
